Las siete familias, en vivo

Una instancia por mosaico

Cada mosaico es su propio canvas y su propio contexto WebGL. Seguí la paleta que elegiste arriba; tocá uno para pasarlo al hero. Los que quedan fuera de pantalla no dibujan.

Uso

<canvas id="fondo" class="fondo"></canvas>   /* position:absolute; inset:0; width/height:100% */

<script type="module">
  import { fondoShader } from "../kit/fondo-shader.js";

  const f = fondoShader(document.getElementById("fondo"), {
    familia: "aurora",   // malla | aurora | metal | semitono | remolino | celdas | llama
    velocidad: 0.8, escala: 1, grano: 0.04, semilla: 0,
    puntero: true,       // lente bajo el cursor (solo mouse)
  });

  f.cambiar({ familia: "metal" });          // en vivo
  f.cambiar({ paleta: ["#0b0d10", "#2a3038", "#59636f", "#a7b0ba", "#f2f4f6"] });
  f.cambiar({ paleta: null });              // vuelve a leer los tokens (cambio de tema)
  const png = await f.foto();               // Blob PNG
  const webm = await f.grabar(6);           // Blob webm
  f.destruir();
</script>

Sin paleta, lee del canvas --tinta, --acento-hondo, --acento, --acento-claro y --hueso. El primer color es siempre el fondo. Acepta hex o cualquier color CSS.

Con "reducir movimiento" dibuja un solo cuadro y queda quieto. Sin WebGL deja un degradé CSS con la paleta.
