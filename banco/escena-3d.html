Qué es y cuándo conviene

Un objeto que se arma solo con código

Sirve para productos simples, objetos de marca o un detalle que el cliente no tiene en foto. Si ya existe un modelo 3D real o un video del producto, ese recurso manda: esto es para cuando no lo hay.

Llega tarde

three.js se baja recién cuando la escena está por entrar en pantalla. Antes, la página solo carga el respaldo.

Cómo se usa

Un contenedor, una función y la cámara

El progreso p llega solo desde el [data-escenario] más cercano. armar puede ser async: se espera a que esté todo antes del primer cuadro.

import { escena3d, camaraPorCapitulos } from "../kit/escena3d.js";

escena3d(document.querySelector("#lienzo"), async ({ THREE, escena, camara, render }) => {
  // …armar la escena con THREE…
  const ir = camaraPorCapitulos(camara, [
    { pos: [3, 1, 9],  mira: [0, 0, 0] },
    { pos: [-3, 1, 7], mira: [0, 0.5, 0] },
  ]);
  return { cuadro(t, dt, p) { ir(p); } };   // p: 0..1 del escenario
}, { dprMax: 2, suavizar: 0.1 });

Todo lo de esta página es procedural: no hay un solo modelo ni textura externa.
